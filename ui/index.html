POWERED BY LIVE-HARNESS (RUST)

Connect any human + AI GitHub organization in three steps

This starter UI reads any ai-org.live.v1 JSON generated by the Rust live-harness CLI — no frontend build step, browser tokens, or repository modifications required.

  1. 01 Configure departmentsEdit organization.json with your departments, GitHub repositories, workflows, and relay routes.
  2. 02 Run the Rust collectorRun live-harness collect --config organization.json --state .live-state/checkpoint.json --output ui/organization.json.
  3. 03 Publish staticallyServe ui/ on GitHub Pages, Vercel, or any static host (or pass ?data=https://.../organization.json).
